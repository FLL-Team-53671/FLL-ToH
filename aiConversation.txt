I built the tracker page in one file, [index.html](index.html). It pulls all 633 tree-of-heaven sightings in Pittsburgh live from iNaturalist and puts them on a street map. Each dot is colored by the tree's status.

I tested it on a local server. All 633 sightings loaded, and saving a "Treated" update changed the counts at the top. I also fixed a bug where updates saved in the evening got the next day's date. I deleted my test entry afterward.

**How it works:**
- **Statuses:** every sighting starts as **Reported – not verified**. A crew can change it to **Verified – alive & healthy**, **Treated** (with *Verticillium nonalfalfae*), **Dead**, or **Not found**. I added "Not found" for when a crew visits and the tree isn't there.
- **Updating a tree:** click a dot or a list row. The crew enters their name, the visit date and notes. For a treatment they can also record trunk diameter and the number of inoculation points. Each tree keeps a full history of these updates.
- **Follow-up reminders:** treated trees that aren't marked dead after 60 days get a "Follow-up" flag so a crew goes back to check for wilt. I picked 60 days as a placeholder; you can change it at the top of the script (`FOLLOW_UP_DAYS`).
- **Tools:** you can filter by status with the chips at the top, search by street, sort by follow-up due, and get directions to each tree. The page warns when an observer hid a sighting's exact location.
- **Safety note:** the About box says only trained, authorized crews, like the USDA Forest Service, should apply the fungus.

**Limits:**
- **Statuses aren't shared.** They save only in the browser where they were entered. Teammates share them with **Export statuses** and **Import statuses**, and an import keeps the newest change for each tree.
- **Anyone can edit.** The page has no logins, so it can't stop someone from changing a status. Shared statuses and real access control would need a small server or database later.

**To run it:** double-clicking the file should work, but I only tested it through a local server. That's the safer way if it doesn't load. From the ToH folder:

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765. I also added a small preview config in `.claude/launch.json` so the page opens in the app's browser pane.
