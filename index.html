How to use this tracker

Each dot is a tree-of-heaven (Ailanthus altissima) sighting posted to iNaturalist in the Pittsburgh place. Every sighting starts as Reported. Field crews update it as they work:

  1. Reported – posted on iNaturalist, nobody has checked it on the ground.
  2. Verified – alive – a crew found the tree and it is living. Ready for treatment.
  3. Treated – inoculated with Verticillium nonalfalfae. Record date, crew and trunk size.
  4. Dead – the tree has died (wilt confirmed or otherwise).
  5. Not found – crew visited and could not find the tree.

Only trained, authorized applicators (for example USDA Forest Service or state agency crews) should apply Verticillium nonalfalfae. Follow the product label and any permits required where you work. Anyone can use this page to view progress.

Statuses are saved in this browser only. Use Export statuses to save a file and Import statuses to load a teammate's file; imports merge by keeping the newest change for each tree.

Treated trees are flagged for a follow-up visit after days if they are not yet marked dead.
